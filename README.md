# Podsjetnik za izlaganje (Slajdovi 17 – 23)

Mobilna aplikacija za čitanje podsjetnika iz daljine tijekom izlaganja (način **Ključne riječi** + **Cijeli tekst**, veliki gumbi za prebacivanje slajdova, povećanje fonta i uvijek uključen ekran).

## Preuzmi aplikaciju za Android

[![Preuzmi APK](https://img.shields.io/badge/PREUZMI_APK-v1.2.3-FFE600?style=for-the-badge&logo=android&logoColor=000000)](https://github.com/KTihana/prompter-slajdovi/releases/download/v1.2.3/PodsjetnikSlajdovi-v1.2.3.apk)

> **Kako instalirati na mobitelu:**
> 1. Dodirni žuti gumb **PREUZMI APK** iznad.
> 2. Otvori preuzetu datoteku `PodsjetnikSlajdovi.apk`.
> 3. Ako Android zatraži dopuštenje za instalaciju iz preglednika (*Nepoznati izvori / Unknown apps*), dopusti i klikni **Instaliraj**.
> 4. Okreni mobitel **vodoravno (landscape)** i po potrebi klikni **`A+`** za još veća slova!
